## ⚠️ 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| 控制台 UI 交互受限 | 高 | 体验不好 | 提前启动 Blazor Web 版 |
| SignalR 连接不稳定 | 中 | 协作体验差 | 添加断线自动重连 + 本地缓存 |
| 菜谱数据不足 | 高 | 用户觉得没用 | 实现爬虫批量导入 + 用户上传激励 |
| 语音识别准确率低 | 低 | 功能鸡肋 | 先做语音输出（播报），输入延后 |
