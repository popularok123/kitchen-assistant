## 🔌 核心模块设计

### 1. 烹饪会话模块 (Cooking Session)

**职责**：管理一个正在进行的烹饪过程

```csharp
public class CookingSession
{
    public Guid SessionId { get; set; }
    public Guid RecipeId { get; set; }
    public string HostUserId { get; set; }
    public List<SessionParticipant> Participants { get; set; }
    public int CurrentStepIndex { get; set; }
    public Dictionary<int, bool> CompletedSteps { get; set; }
    public Dictionary<int, TaskAssignment> TaskAssignments { get; set; }
    public DateTime StartTime { get; set; }
    public CookingSessionStatus Status { get; set; }
}

public enum CookingSessionStatus
{
    Preparing,
    Cooking,
    Paused,
    Completed,
    Cancelled
}
```

**核心流程**：
1. 用户选择菜谱，创建烹饪会话
2. 邀请其他用户加入会话
3. 分配各步骤任务
4. 实时同步进度
5. 完成后归档会话

## 📡 SignalR Hub 设计

### CookingHub 消息定义

| 客户端调用 | 服务端广播 | 说明 |
|-----------|-----------|------|
| `JoinRoom(userName)` | `UserJoined(user)` | 用户加入 |
| `LeaveRoom()` | `UserLeft(user)` | 用户离开 |
| `SendMessage(content)` | `ReceiveMessage(msg)` | 发送消息 |
| `StartCooking(recipeId)` | `CookingStarted(session)` | 开始烹饪 |
| `UpdateStep(stepIndex)` | `StepUpdated(sessionId, step)` | 步骤更新 |
| `AssignTask(stepId, userId)` | `TaskAssigned(task)` | 分配任务 |
| `CompleteStep(stepId)` | `StepCompleted(stepId, userId)` | 完成步骤 |

## 🔊 语音服务设计

### 跨平台 TTS 抽象

```csharp
public interface ITextToSpeechService
{
    Task SpeakAsync(string text, CancellationToken cancellationToken = default);
    void Stop();
    bool IsSpeaking { get; }
    event EventHandler<SpeechEventArgs> SpeakStarted;
    event EventHandler<SpeechEventArgs> SpeakCompleted;
}

// 各平台实现
public class MacTextToSpeechService : ITextToSpeechService  // say 命令
public class WindowsTextToSpeechService : ITextToSpeechService  // SpeechSynthesizer
public class WebTextToSpeechService : ITextToSpeechService  // Web Speech API
public class AzureTextToSpeechService : ITextToSpeechService  // Azure 云服务
```
