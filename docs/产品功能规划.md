# 🍳 厨房协作助手 - 产品功能规划

## 产品定位

**一个专注于多人协作烹饪的厨房助手软件**

- 核心价值：让做饭不再孤单，多人协作更有趣
- 目标用户：家庭用户、朋友聚会、合租室友
- 差异化：实时协作 + 语音交互 + 社交化烹饪

## 🎨 核心场景设计

### 场景一：朋友聚会做饭
> 周末 4 个朋友一起在家做饭

1. 大家一起在 App 里选菜谱
2. 系统自动分配任务：
   - A：洗菜切菜
   - B：炒菜
   - C：做汤
   - D：准备甜品
3. 每个人手机上看到自己的任务列表
4. 完成一个任务就打勾，所有人都能看到进度
5. 做完一起拍照打卡，记录这次聚会

### 场景二：家庭日常做饭
> 夫妻二人，平时上班忙

1. 周日晚上一起规划下周晚餐
2. 系统自动生成购物清单
3. 下班路上谁顺路谁买菜，清单实时同步
4. 谁先到家谁开始准备，进度实时同步
5. 做完记录口味评价，下次改进

### 场景三：远程指导父母
> 在外地工作，教爸妈学做新菜

1. 选好菜谱分享给爸妈
2. 开启"直播间模式"
3. 爸妈跟着步骤做，遇到问题发语音
4. 你在手机另一端实时指导
5. 完成后拍照打卡，记录"教爸妈做的第N道菜"
